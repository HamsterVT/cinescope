Истории имеют значение.

CineScope — независимый каталог для тех, кто любит выбирать кино так же, как смотреть его.

Найдите своё

Здесь можно искать фильмы, знакомиться с актёрами и режиссёрами, открывать тематические подборки и собирать личный список «Буду смотреть».

Источники данных

Стартовый каталог — редакционная подборка фильмов и сериалов. Описания подготовлены для проекта. Оценки — справочные значения стартовой подборки; они не обновляются в реальном времени и не являются пользовательскими оценками CineScope.

Постеры и кадры загружаются с TMDb. This product uses the TMDB API but is not endorsed or certified by TMDB. The Movie Database

Ваш список

Без входа список хранится только в этом браузере. В аккаунте списки просмотра и оценки сохраняются в облаке и доступны с других устройств. Локальный список можно перенести в профиль отдельной кнопкой. Настройку видимости профиля можно менять. Сохранённые фильмы и покупки видны только вам. CineScope не использует рекламные трекеры.

Смотреть кино

Открытые фильмы доступны в разделе «Смотреть». На странице просмотра указаны студия и источник. Для части каталога доступны трейлеры и ссылки на официальные платформы.
