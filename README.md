# CineScope

Русскоязычный каталог фильмов и сериалов на Django 5.2. В проекте есть поиск и фильтры, карточки и трейлеры, профиль с облачной библиотекой, плеер с продолжением просмотра и CineScope Plus с оплатой через BTCPay.

- [Открыть сайт на Vercel](https://cinescope-beta-five.vercel.app/)
- [Исходный код на GitHub](https://github.com/HamsterVT/cinescope) (приватный репозиторий, требуется доступ)
- [Раздел «Смотреть»](https://cinescope-beta-five.vercel.app/watch/)

## Быстрый запуск

Понадобится Python 3.11–3.14. Выполните в папке проекта.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
DJANGO_DEBUG=1 python manage.py runserver
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Главная, каталог, поиск и каталог трейлеров работают из редакционных данных. Django читает настройки из окружения. Шаблон переменных находится в `.env.example`.

## Что показать

- **Главная и каталог.** «Человек-паук: Новый день», поиск по названию, жанры и фильтр доступных фильмов.
- **Плеер.** Откройте раздел «Смотреть» и войдите в CineScope. Открытые фильмы Blender воспроизводятся в плеере. Закройте страницу после начала фильма и откройте **Профиль → Мои просмотры**, чтобы продолжить.
- **Подписка.** По кнопке Plus можно посмотреть тарифы и оформление. Подключённый BTCPay создаёт счёт в Bitcoin. Тарифы указаны в тенге.
- **Администрирование.** Роли пользователя и администратора отделены. В **Управление → Видеоисточники** администратор может привязать разрешённый MP4/WebM или официальную страницу показа к карточке.

У фильма «Человек-паук: Новый день» есть официальный трейлер и ссылка Sony. Полный показ в рабочей сборке зависит от настроенного видеоисточника и доступа аккаунта.

## Структура проекта

| Путь | Содержимое |
| --- | --- |
| `config/`, `manage.py` | Настройки Django, маршруты, точка входа WSGI |
| `catalog/` | Каталог, аккаунты, просмотр, платежи, тесты |
| `catalog/data/` | Редакционный каталог и открытые фильмы |
| `templates/`, `static/` | HTML-шаблоны, стили, JavaScript и изображения |
| `supabase/` | Миграции облачной базы, конфигурация Auth и шаблоны писем |
| `requirements.txt`, `pyproject.toml`, `vercel.json` | Зависимости и конфигурация сборки |

## Настройка облака и публикация

Для собственной установки создайте Supabase-проект и примените SQL к **новой** базе в указанном порядке.

1. `catalog/library_schema.sql`.
2. `catalog/profile_schema.sql`.
3. `catalog/roles_schema.sql`.
4. Файлы `supabase/migrations/` в порядке возрастания имён.

Задайте `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` и `SITE_URL`. Для входа задайте SMTP и разрешённый callback `/account/callback/` либо настройте Telegram OIDC в Supabase. Флаги `AUTH_EMAIL_READY` и `AUTH_TELEGRAM_READY` включаются после настройки соответствующего провайдера. Личные просмотры и права записи ограничивает RLS. Назначение роли администратора выполняется владельцем проекта через `public.user_roles`.

По умолчанию каталог использует `MOVIE_PROVIDER=local`. Для TMDb задайте `MOVIE_PROVIDER=tmdb` и `TMDB_READ_TOKEN`. Для своей PostgreSQL задайте `DATABASE_URL`, выполните `python manage.py migrate`, `python manage.py seed_catalog` и выберите `MOVIE_PROVIDER=database`.

На Vercel подключите папку проекта, задайте уникальный `DJANGO_SECRET_KEY`, укажите production-домен в `SITE_URL` и оставьте `DJANGO_DEBUG=0`. Для BTCPay нужны собственный магазин, кошелёк и серверные переменные из `.env.example`. Webhook принимает подписанные уведомления на `/billing/btcpay/webhook/`. Для собственного видеохостинга укажите его HTTPS-домен в `VIDEO_MEDIA_HOSTS`. Видео доставляется напрямую браузеру и поддерживает перемотку при наличии HTTP Range.

Для закрытого показа допустимый временный источник настраивается через `CINESCOPE_DEMO_MP4` и перечень разрешённых аккаунтов `CINESCOPE_DEMO_USERS`. Эти настройки задаются серверными секретами. Рабочие ключи, пользовательские данные и полные видеофайлы не входят в исходники.

## Проверки

```sh
python manage.py check
python manage.py test --noinput
python manage.py collectstatic --noinput
```

Метаданные и обложки используют материалы TMDb, Sony Pictures и Blender Studio. Атрибуция открытых фильмов показана в плеере. Материалы правообладателей используются для карточек и демонстрации проекта.
